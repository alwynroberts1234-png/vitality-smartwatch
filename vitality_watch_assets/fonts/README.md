# Fonts

Font files are not included in this package.

Recommended:
- Primary UI: Inter
- Large numeric values: Inter Tight or Roboto Condensed
- Development fallback: DejaVu Sans

Suggested LVGL sizes:
- Caption: 16 px
- Body: 20 px
- Subtitle: 24 px
- Title: 30 px
- Metric values: 52 px
- Watch time: 84 px
